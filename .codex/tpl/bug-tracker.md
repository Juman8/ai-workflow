### 優先度定義

| 優先度 | 定義 | 対応期限 |
|--------|------|---------|
| P1（重大） | システム停止・データ損失・セキュリティ脆弱性 | 即日 |
| P2（高） | 主要機能が使えない | 翌営業日 |
| P3（中） | 機能の一部が使えない・回避策あり | 今スプリント内 |
| P4（低） | 軽微な表示崩れ・文言ミス | 次スプリント以降 |

### ステータス定義

| ステータス | 説明 |
|-----------|------|
| 未対応 | バグが登録されたが担当者未割り当て |
| 対応中 | 担当者が修正作業中 |
| レビュー待ち | 修正完了・レビュー待ち |
| 確認待ち | 修正後のテスト確認待ち |
| クローズ | 修正確認済み・完了 |
| 保留 | 対応を次フェーズ以降に延期 |
