### Priority Definitions

| Priority | Definition | Response Deadline |
|----------|-----------|------------------|
| P1 (Critical) | System outage · Data loss · Security vulnerability | Same day |
| P2 (High) | Core features unavailable | Next business day |
| P3 (Medium) | Part of a feature unavailable · Workaround exists | Within current sprint |
| P4 (Low) | Minor display issue · Typo | Next sprint or later |

### Status Definitions

| Status | Description |
|--------|------------|
| Open | Bug registered but no assignee |
| In Progress | Assignee is working on the fix |
| Pending Review | Fix complete · Awaiting review |
| Pending Verification | Awaiting test verification after fix |
| Closed | Fix verified · Complete |
| Deferred | Response postponed to next phase or later |
