# .claudeignore サンプル

> プロジェクトルートに `.claudeignore` として配置することで、
> Claude Code がファイルを読み込む際に無視するパスを指定できます。
> トークン消費の削減・機密情報の保護に活用してください。

---

## 使い方

`.claudeignore` は `.gitignore` と同じ構文を使います。

```
# ← # でコメント
*.log          ← すべての .log ファイルを無視
dist/          ← dist ディレクトリ以下を無視
!src/important.ts  ← ! で除外ルールを打ち消す
```

## トークン削減の目安

| 対象 | 削減効果 |
|------|---------|
| `node_modules/` を除外 | 大（数十万トークン） |
| `dist/` `build/` を除外 | 中（数万トークン） |
| `coverage/` を除外 | 小〜中 |
| ログ・一時ファイルを除外 | 小 |

---

## 注意事項

- `.claudeignore` に追加しても `.gitignore` には影響しません（別ファイルです）
- 実装に必要なファイルを誤って除外しないよう注意してください
- CLAUDE.md の `.claudeignore 参照` セクションにこのファイルへのリンクを記載しておくと運用しやすくなります
