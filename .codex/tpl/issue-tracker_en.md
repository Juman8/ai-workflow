## Type Definitions

| Type | Description | Examples |
|------|------------|---------|
| Issue | A problem or obstacle requiring action | Specification conflicts, technical problems, schedule delays |
| Concern | Something not yet a problem but requiring attention | Risk factors, policies under consideration |
| Decision | Items agreed upon or decided as a result of discussion | Technology selection decisions, specification finalization |
| Question | Items to confirm with the client or stakeholders | Ambiguous requirements, specification clarifications |
| Change | Scope or specification change requests | Additional feature requests, specification changes |

## Status Definitions

| Status | Description |
|--------|------------|
| Open | Not yet started |
| Under Review | Response policy under consideration |
| In Progress | Owner is working on it |
| Awaiting Confirmation | Waiting for response from client or stakeholders |
| Closed | Response complete · Resolved |
| On Hold | Response temporarily paused (note reason in the Notes column) |
| No Action Required | Decided not to address |
