## DoD（完成の定義）

スプリントバックログアイテムが「完了」とみなされる条件：

- [ ] コードレビュー完了・マージ済み
- [ ] 自動テスト（ユニット・統合）が通過している
- [ ] 受け入れ条件を満たすことを確認済み
- [ ] 関連ドキュメント（画面設計書・API仕様書）を更新済み
- [ ] ステージング環境で動作確認済み

## ステータス定義

| ステータス | 説明 |
|---------|------|
| 未着手 | まだ着手していない |
| 進行中 | 開発中 |
| レビュー待ち | PR・コードレビュー待ち |
| テスト中 | テスト・受け入れ確認中 |
| 完了 | DoDを満たした |
| 持越し | 次スプリントへ持越し |

## 優先度定義（MoSCoW）

| 優先度 | 説明 |
|--------|------|
| Must | このスプリントで必ず完了すること |
| Should | できれば完了させたいこと |
| Could | 余裕があればやること |
| Won't | このスプリントでは行わない |
