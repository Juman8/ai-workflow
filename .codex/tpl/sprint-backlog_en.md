## DoD (Definition of Done)

Conditions for a sprint backlog item to be considered "complete":

- [ ] Code review complete · Merged
- [ ] Automated tests (unit · integration) passing
- [ ] Acceptance criteria verified as met
- [ ] Related documents (screen design, API spec) updated
- [ ] Verified working in staging environment
